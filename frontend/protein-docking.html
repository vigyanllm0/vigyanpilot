What is this tool?

A protein-ligand molecular docking platform that predicts how small molecules bind to protein targets. It combines ESMFold for protein structure prediction from amino acid sequences, AutoDock Vina for physics-based pose screening, and GNINA for deep-learning re-scoring. Built for structural biologists and computational chemists who need reliable binding affinity predictions.

Frequently Asked Questions About Protein Docking Tool

Everything you need to know about using this tool

Is the docking tool free?

The docking tool starts at ₹49 for your first run (50% off). Molecular docking is computationally intensive, so token packs and subscriptions provide the best value for regular use.

What docking algorithms are used?

The tool uses AutoDock Vina for physics-based pose screening and GNINA for CNN re-scoring. The consensus pipeline combines both methods for more reliable predictions.

What file formats are accepted?

The tool accepts amino acid sequences (text) and SMILES strings for ligands. PDB file support is planned for a future release.

Do I need an account?

No, you can run a basic docking without an account. Creating an account helps track your results and access advanced features like batch screening and export.
