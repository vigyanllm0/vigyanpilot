How to Export from Your Instrument

Bio-Rad CFX Maestro (.pcrd files)

Option A (recommended): Export as RDML 1.2 → File → Export → "Export as RDML" → upload the .rdml file here (full data, all wells, melt curves).
Option B: Export as CSV → File → Export → "Export to CSV" → select "Well, Fluor, Target, Content, Cq" + amplification cycles → upload here.
Why not .pcrd directly? .pcrd is Bio-Rad's proprietary binary format. We detect .pcrd uploads and guide you to export. (v1.1 will add experimental .pcrd support — research spike in progress.)

Applied Biosystems QuantStudio

.eds files drop in directly — the EDS bundle is read natively: per-well Cq, sample/target names, Delta Rn curves, and the instrument/run-state metadata are all picked up from apldbio/sds/analysis_result.txt inside the file. For CSV instead: 1. Open results in QuantStudio Design & Analysis → 2. File → Export → "Results" (CSV) → 3. Include amplification data → 4. Upload the CSV here. For melt data, export "Melt Curve" separately.

Any instrument (CSV / TSV / TXT)

Drop in the export as-is — no conversion, no fixed column order. The analyzer reads the file's content, not its name: it detects the delimiter (comma, tab, semicolon, pipe), the encoding (UTF-8 / UTF-16), maps 80+ column spellings (Well/Position/Chamber · Sample/Specimen · Target/Assay/Oligo · Reporter/Dye/Channel · Ct/Cq/Value), and reasons about wide cycle tables or long per-cycle tables. Cq-only exports are accepted too — the charts will say so instead of drawing empty plots.

Generic Template

Download the template TSV. Fill in Well, Sample, Target, Channel, Cq, and optional Amplification (semicolon-separated). Upload here. Works with any instrument.

Excel (.xlsx)

Upload any .xlsx — no template needed. The first sheet with recognizable columns is read: wide tables (one column per cycle), long tables (Cycle/Signal per well), or Cq tables. Encrypted workbooks and files with no recognizable table get a format card explaining what was found.

Legacy Excel (.xls)

.xls files are read natively (OLE2/BIFF8) — no conversion needed. Older instrument software often writes .xls; just drop the file. If a sheet doesn't contain a recognizable table, the format card shows what was found in each sheet.

Rotor-Gene family (.qbd / .qbg / .rex — Qiagen Rotor-Gene, OnePCR, RapiCycler)

These vendors ship proprietary binary files. The analyzer probes the file's content first: if it's actually an OLE2 or ZIP container inside (some exports are), it parses directly — and if it's a short printable vendor header followed by a gzip stream (a shape several of these tools use for their text-table exports), the stream is decompressed and the inner table read automatically. If the payload is a vendor run database (schema-keyed binary, no data table), you get a guided format card that reports what it found — schema keys, run timestamps, embedded labels — plus the exact export path from your software (usually File → Export → CSV or Excel); that export carries the same data (Cq values and curves) and needs no manual conversion beyond that one step.

ZIP Archives

ZIP files are deep-probed automatically: inner .csv/.tsv/.txt/.rdml/.xlsx entries (up to 1 MB) are located and read. Drop the whole ZIP — no extraction needed. If the archive doesn't contain run data, the format card lists what it does contain.

Frequently Asked Questions

How do I analyze qPCR data?

Upload your run file (any instrument CSV/TSV export, Excel .xlsx/.xls, or RDML) → the analyzer shows amplification curves, melt peaks, standard curves, and fold-change expression. No login required, data stays in your browser.

What is real-time PCR data analysis?

Real-time PCR data analysis involves interpreting amplification curves, Cq values, melt curves, and standard curves to quantify gene expression. This tool automates the process from raw data to fold-change results.

How do I interpret a Ct curve?

The Ct (cycle threshold) curve shows fluorescence vs cycle number. A lower Ct means more starting template. The curve shape reveals amplification efficiency and potential artifacts.

How do I calculate fold change from qPCR?

Fold change is calculated using ΔΔCq (Livak method) or efficiency-corrected Pfaffl method. This tool computes both automatically from your data with reference genes and calibrator selection.

What is qPCR raw data?

qPCR raw data is the fluorescence readings per cycle per well, exported from your instrument. This tool accepts any instrument CSV/TSV/TXT export, Excel .xlsx/.xls, RDML 1.2, and CFX exports — read by content, not by file name.

Why was my .qbd file not read directly?

.qbd (and .qbg/.rex) are proprietary binary formats from the Rotor-Gene software family (Qiagen Rotor-Gene, OnePCR, RapiCycler). The analyzer probes the file's content first — OLE2 or ZIP containers inside parse directly, and a printable vendor header followed by a gzip-compressed table unwraps and reads automatically. If the payload is a vendor run database (schema-keyed binary with no data table), a format card reports what was found — schema keys, run timestamps, embedded labels — and gives your software's own export step; the exported CSV/Excel carries the same Cq and curve data.

How do I interpret curve data?

Amplification curves show exponential growth phase; melt curves show product specificity; standard curves show efficiency and R². QC flags highlight problematic wells automatically.
