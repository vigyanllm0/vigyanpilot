Primer Design Glossary

Essential vocabulary for designing PCR primers — from melting temperature and GC content to secondary structure and specificity checking.

Annealing Temperature

The PCR step temperature at which primers bind complementary template DNA. Typically set 3–5 °C below the lower primer Tm.

Read definition →

GC Content

The percentage of guanine and cytosine bases in a DNA sequence. Affects melting temperature, primer stability, and PCR specificity.

Read definition →

GC Clamp

One or more guanine or cytosine bases at the 3′ end of a primer that increase binding stability at the primer–template junction.

Read definition →

Melting Temperature (Tm)

The temperature at which half of a DNA duplex dissociates into single strands. Calculated via nearest-neighbor thermodynamics.

Read definition →

Hairpin

A secondary structure where a primer folds back on itself, forming a stem-loop that competes with template binding and reduces PCR efficiency.

Read definition →

Primer Dimer

Non-specific amplification products formed when two primers anneal to each other instead of the template, consuming reagents and reducing yield.

Read definition →

Primer Specificity

The ability of a primer to bind exclusively to the intended target sequence without cross-reacting with off-target regions in the genome.

Read definition →

Forward Primer

The primer that binds the antisense strand and extends in the 5′→3′ direction, matching the sense strand sequence of the target region.

Read definition →

Reverse Primer

The primer that binds the sense strand and extends in the 5′→3′ direction, complementary to the sense strand of the target region.

Read definition →

Degenerate Primer

A primer containing ambiguous bases (IUPAC codes) at specific positions to account for codon degeneracy when targeting conserved protein motifs.

Read definition →

Primer Design

The process of selecting optimal oligonucleotide sequences for PCR amplification, considering Tm, GC%, specificity, and secondary structures.

Read definition →

Delta-G (ΔG)

Gibbs free energy of folding; more negative ΔG values indicate more stable secondary structures like hairpins and dimers.

Read definition →

Salt Correction

Adjustments to Tm calculations accounting for monovalent cation (Na⁺) concentration, which screens phosphate backbone charges.

Read definition →

Mg²⁺ Correction

Tm adjustment for magnesium ion concentration, which stabilizes duplexes more strongly than monovalent cations and affects PCR fidelity.

Read definition →

Nearest-Neighbor Model

A thermodynamic model that calculates duplex stability from the stacking interactions of adjacent base pairs rather than individual bases.

Read definition →

SantaLucia 1998

The landmark paper providing standardized nearest-neighbor thermodynamic parameters for DNA duplex stability calculations used in primer design.

Read definition →

IUPAC Codes

Ambiguous nucleotide notation (R, Y, S, W, K, M, B, D, H, V, N) used to represent degenerate positions in primer sequences.
