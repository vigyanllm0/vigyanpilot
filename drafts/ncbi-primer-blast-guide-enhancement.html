How do I use NCBI Primer-BLAST?

To design specific primers using NCBI Primer-BLAST:

  1. Go to ncbi.nlm.nih.gov/tools/primer-blast
  2. Enter your target sequence (or paste an accession number)
  3. Set primer size (18-25 bp), Tm (57-63°C), GC% (40-60%)
  4. Select your organism's genome database for specificity check
  5. Click "Get Primers" — Primer-BLAST finds primers and checks specificity in one step
